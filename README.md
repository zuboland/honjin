登録不要・無料。Windows対応（ZUBOLAND株式会社名義のコード署名済み）。

- 開発元: [ZUBOLAND株式会社](https://zuboland.jp)
- 本体のソースは非公開です。**拡張API（Source / Watch / View）は公開仕様**で、誰でも足せます。

## なにをする道具か

HONJIN は、自分が使っている道具から「出来事」を集めて、**1本の時系列**にして見るデスクトップアプリです。

見せるのは **現在値ではなく「動き」** です。
売上グラフやKPIの数字を並べるのではなく、「なにが起きたか」を時間順に流します。
その日に出た数字や失敗が、流れて消えずに次に使える材料として残るように、
どの出来事からでもその場でメモ（カード）を書けます。

集める先は自分で設定します。集めた出来事は、**追記だけの JSONL ファイル**として手元に残ります。

> **正直に書いておくこと**
> HONJIN は ZUBOLAND 自身の運用のために作っているので、
> 「状態」の面（講座・公開サイト・製品）は自社の UNIシリーズに強く寄っています。
> UNIシリーズを使っていない場合、そこは空のままになります。
> **どなたでもすぐ使えるのは「AIセッション」「監視（Watch）」「原液カード」の3つ**です。

## できること

| 面 | 中身 |
|---|---|
| **プロジェクト（川）** | 集めた出来事を、プロジェクト単位で時系列に流す。追記だけの `events.jsonl` |
| **AIセッション** | PCの中で動いている AI（Claude Code / Codex / OpenCode / Gemini / Copilot / Ollama）の**ローカルの痕跡を直接読む**。いま何が動いていて、どのファイルで衝突しているかが1面で見える |
| **監視（Watch）** | サイト・フォルダ・API・コマンド・リリース・MCPサーバーの変化を見張る。判定の型は6種 |
| **原液カード** | どの出来事からでもメモを1枚書ける。数字・失敗・引っかかった点を、その場で残す |
| **拡張機能** | `plugins` フォルダに置いたものが、そのまま増える。フォルダ名の頭に `_` を付けると止まる |

**外部への送信はありません。** 通信するのは、あなたが自分で設定した先と、更新確認だけです。

## インストール

| OS | ファイル | 備考 |
|---|---|---|
| **Windows 10 / 11**（64bit） | [`HONJIN-Setup-x.y.z.exe`](https://github.com/zuboland/honjin/releases/latest) 約97MB | 実行するだけ。**管理者権限は不要**（ユーザー領域にインストールされます） |

- **ZUBOLAND株式会社名義のコード署名済み**です。通常 SmartScreen の警告は出ません。
  もし出た場合は「詳細情報」→「実行」で進めます（署名の浸透待ちで出ることがあります）。
- Python など追加のランタイムは要りません。必要なものは同梱しています。
- macOS / Linux 版はまだありません。

## 最初の3ステップ

1. **起動する。** 初回起動時に、あなたのPCの中に作業場（workspace）が作られます。
2. **「AIセッション」の面を開く。** 設定なしで、PC内のAIの痕跡がそのまま並びます。
3. **監視をひとつ足す。** `watch/example.yaml` を開き、コメントを外して自分のサイトのURLに書き換えて保存します。

```yaml
- id: my-lp
  kind: site        # site / folder / api / command / release / mcp の6種
  name: 自社LP
  url: https://example.com
  every: 6h
```

## 拡張のしかた（Source / Watch / View）

拡張は**フォルダに置いたただのファイル**です。ビルドも申請も要りません。

| 種類 | なにをするもの | 置き場所 |
|---|---|---|
| **Source** | 出来事を川に流す（自分の道具・APIからの取り込み） | `plugins/<名前>/` |
| **Watch** | 見張る対象を YAML で書く（6種の判定） | `watch/*.yaml` |
| **View** | 見せ方を足す（サンドボックス内で動く HTML 画面） | `plugins/<名前>/` |

- フォルダ名の頭に `_` を付けると、その拡張は**読み込まれません**（消さずに止められます）。
- View は隔離された枠の中で動きます。ローカルのファイルやネットワークに直接は触れません。
- 詳しい書き方は、アプリ内の「拡張機能」の面と、`plugins/README.md` に入っています。

## データはどこに保存されるか

**すべてあなたのPCの中だけです。**

| データ | 場所（Windows） |
|---|---|
| 作業場ぜんぶ | `%APPDATA%\HONJIN\workspace\` |
| 出来事の川 | 同 `stream\`（`events.jsonl` ＝ 追記のみ。テキストなので他のツールでも読めます） |
| 監視の定義 | 同 `watch\` |
| 拡張 | 同 `plugins\` |
| 書いたカード | 同 `vault\`（保存先は設定から変えられます） |

出来事の中身が外部に送られることはありません。

## 更新

- 起動すると、新しい版が出ていないかを **GitHub Releases の最新** に確認しに行きます。
- 更新は「設定・情報」→「更新を確認」からも実行できます。
- ダウンロード先は **公式リリースの資産だけ**に固定しています（リダイレクト先も毎回確認します）。
  そのため、更新と称して別のファイルを掴まされることがありません。

## アンインストール

Windows の「設定 → アプリ」から HONJIN を削除します。

- **作業場（`%APPDATA%\HONJIN\workspace\`）は残ります。** 入れ直すとそのまま続きから使えます。
- 完全に消したい場合は、アンインストール後にこのフォルダを手で削除してください。

## よくある質問

<details>
<summary><b>会社のデータを外部に置きたくないのですが</b></summary>

HONJIN は外部にデータを預けません。集めた出来事はあなたのPCの中のファイルとして残ります。
通信するのは、あなたが自分で設定した取得先と、更新確認だけです。
</details>

<details>
<summary><b>UNIシリーズを使っていなくても意味がありますか？</b></summary>

「AIセッション」「監視」「カード」は単体で使えます。
一方で「講座」「公開サイト」「製品」の面は自社サービス前提なので、空のままになります。
</details>

<details>
<summary><b>ソースは公開しないのですか？</b></summary>

本体は非公開です。代わりに**拡張の仕様を公開**しています。
自分の道具を繋ぎたい場合は、本体を触らずに Source / Watch / View を足してください。
</details>
