# HONJIN（本陣）

**事業の今と動きを、手元の1画面で見る作業台。**
ダッシュボードを10個開かなくても、今日なにが動いたかが分かります。

配布物（インストーラ）は [Releases](https://github.com/zuboland/honjin/releases/latest) から。
登録不要・無料。Windows と macOS に対応（Windows＝ZUBOLAND株式会社名義のコード署名済み／macOS＝Apple 公証済み）。

- 製品ページ: https://zuboland.jp/products/honjin
- 開発元: [ZUBOLAND株式会社](https://zuboland.jp)
- 本体のソースは非公開です。**拡張API（Source / Watch / View）は公開仕様**で、誰でも足せます。

## なにをする道具か

HONJIN は、自分が使っている道具から「出来事」を集めて、**1本の時系列**にして見るデスクトップアプリです。

見せるのは **現在値ではなく「動き」** です。
売上グラフやKPIの数字を並べるのではなく、「なにが起きたか」を時間順に流します。
その日に出た数字や失敗が、流れて消えずに次に使える材料として残るように、
どの出来事からでもその場でメモ（カード）を書けます。

集める先は自分で設定します。集めた出来事は、**追記だけの JSONL ファイル**として手元に残ります。

> **正直に書いておくこと**
> HONJIN は ZUBOLAND 自身の運用のために作っているので、
> 「状態」の面（講座・公開サイト・製品）は自社の UNIシリーズに強く寄っています。
> UNIシリーズを使っていない場合、そこは空のままになります。
> **どなたでもすぐ使えるのは「AIセッション」「プロジェクト」「ファイル」「監視（Watch）」「原液カード」の5つ**です。

## できること

| 面 | 中身 |
|---|---|
| **プロジェクト** | 事業・製品・取り組みごとにプロジェクトを持ち、AI との会話（人が出した指示・AI の最後の発言・触ったファイル）を AI が読んで、**どのプロジェクトの作業かを振り分け、進捗を記録していく**（やったこと・分かったこと・決まったこと・次の一手）。カードを押すと、その記録が日ごとに読める。会話が続いた分だけを新しい記録にし、20分ごとに書き足す。一覧に無い事業は AI が見つけて作る（印つき・名前は直せる）。名前を変えると旧い名前は別名に残り、以前の呼び名の会話も同じプロジェクトに入る。まとめる・しまう・記録を別のプロジェクトへ移す、は画面からできる。プロジェクトは「プロダクト」「事業案」のような**グループ（上の階層）**にまとめられ、グループ→プロジェクト→進捗の記録の順にたどれる。AI が新しい事業を作るときは既存のグループから入れ先を選ぶ。作業した AI が進捗を直接1件書き込む口もある（同じ会話を自動の書き起こしが二重に書かない）。**あなたの AI（Claude Code・Codex・Cursor など）が作業の区切りで進捗を書ける「受け取り箱」**もある：画面の「AIに書かせる」で出る文を AI の指示ファイル（CLAUDE.md・AGENTS.md など）に貼ると、AI が作業場の `inbox/progress/` に JSON を1つ置き、HONJIN が1分ほどで取り込む（形が違うものは理由つきで `_bad` に分け、画面に出す。同じ中身は二度取り込まない）。プロジェクトを開くと**月次報告の下書き**も作れる（その月の進捗の記録だけから「進捗を書くAI」で下書きし、記録に無い数字・書き落とした失敗・文章の癖を機械で検査する。記録が0件の月は AI を呼ばずに「今月は動きがありません」と書く。宛名を足して送るのはあなた。HONJIN は送信しない。「Gmailで開く」を押すと、プロジェクトに登録した送り先・件名・本文を入れた Gmail の作成画面が開き、本文はクリップボードにも写る。本文が長すぎて作成画面に入れられないときは、貼り付けるよう案内する。送信は Gmail であなたが押す）。出来事の時系列（川）の表示も残している。元の出来事は追記だけの `events.jsonl` |
| **ファイル** | 自分で登録したフォルダ・ファイルだけを、アプリの中で読む。Markdown は見出し・表・チェックリストを整形し、CSV は表、画像とテキストもそのまま表示。PDF・Office文書は既定のアプリで開く。**読むだけで、書き換え・削除はしない**。登録した場所の外は開けず、`.env` や秘密鍵のような鍵・認証情報らしいファイルは中身を表示しない |
| **AIセッション** | PCの中で動いている AI（Claude Code / Codex / OpenCode / Gemini / Copilot / Ollama）の**ローカルの痕跡を直接読む**。いま何が動いていて、どのファイルで衝突しているかが1面で見える |
| **監視（Watch）** | サイト・フォルダ・API・コマンド・リリース・MCPサーバーの変化を見張る。判定の型は6種 |
| **原液カード** | どの出来事からでもメモを1枚書ける。数字・失敗・引っかかった点を、その場で残す |
| **発信（素材→書く→受付履歴）** | 「素材」の面に、体験の原文・自分で確かめた判断・来歴・公開範囲を残す（数字を伴わない判断も残せる）。素材を選び、読者と伝えたいことを入れて「AIで1本作る」か「自分で書き始める」。「書く」の面では、素材・本文・根拠を同じ画面に並べ、保存・再検査・出典の確認・承認までを1画面で行う。本文・媒体・タイトル・原液・導線が変わると、検査と承認は失効する。機械検査（数字の照合・文体・文体の統計的な近さ）を通し、**あなたが承認したものだけ**が X／LINE／メルマガ／note へ出る。送信は先に台帳へ記録するので、同じ原稿が二重に出ない。受け取り結果が分からないものは自動で送り直さず、「受付履歴」で接続先を見て照合してから記録する。下書きを作る前に**あなたに1問だけ聞き**（作る前の1問・既定はオフ）、答えを言い回しのまま下書きの芯にするよう AI に指示する。媒体ごとに**読者と狙い**（役に立つ・学び・気づき・興味づけ）を決められ、1行目が話の途中から・読者に通じにくい語の多さ・です/ますの混ぜすぎ・教訓で締める・決め台詞・あなたが三人称で出る、を🟡で知らせる。X／note／Instagram の各 playbook の検査は、その playbook を契約している環境でだけ動く（無ければ「契約者向け」と表示）。原液の仕分け方針（例: AI系は発信しない／マインドセットだけ発信）は「原液棚」、1日に何本作るか・どのAIに書かせるか・記事の最後の導線・自動配信・UNI製品への接続は「発信工場」で決める |
| **文体（口調）** | お手本フォルダに入れた**あなたが実際に書いた文章**から、語尾・接続詞・文の長さ・行の作り方・記号の密度を機械で測り、書く指示と検査の基準にする（AIに性格を推測させる方式ではない）。母数が足りない項目は自動で無効になり「あと◯通」が出る。**文体パック**を書き出せば、自分の Claude／ChatGPT でも同じ指示・同じ物差しで書ける。左メニュー「文体」で、媒体ごと（メルマガ／LINE／X／Instagram／Threads／note）に**タイトルの傾向・最初の一行・最後の一行・本文の決めごと**を「お手本から測る／自分で決める」で持てる |
| **拡張機能** | `plugins` フォルダに置いたものが、そのまま増える。フォルダ名の頭に `_` を付けると止まる |

**外部への送信はありません。** 通信するのは、あなたが自分で設定した先と、更新確認だけです。
ただし「発信」で下書きを書かせるとき、「原液の方針」で曖昧なカードを AI に仕分けさせるとき（オートモードと同じエンジン）、「プロジェクト」の進捗を AI に記録させるとき（既定はオートモードと同じAI。プロジェクト画面で「使わない」に切り替えられる。渡すのは AI への指示・AI の最後の発言・触ったファイル名と、登録したプロジェクトの名前・説明・別名・グループ名）、「プロジェクト」で月次報告の下書きを作るとき（渡すのはその月の進捗の記録。プロジェクト名と別名は伏せて渡す）は、選んだ AI（PC の中の Ollama か、あなたが入れている claude／codex の CLI）に材料やカードの本文が渡ります。発信の下書きでは、**あなたのお手本の原文（X・Threads など短い投稿は最大4通、それ以外は最大2通）も指示と一緒にそのAIへ渡ります**。「作る前の1問」に答えていれば、その答えも渡ります。「作る前の1問」の画面で**名前を入れると、下書きを作る前に材料をもう1回同じ AI へ渡し**、誰が何をしたか（あなた／AI／ほかの人）を分けてから書かせます（分けた結果は PC の中に残ります）。Ollama なら PC の外に出ません。お手本の原文と文体の定義の保存先は PC の中だけです。

## 最初の3ステップ

1. **起動する。** 初回起動時に、あなたのPCの中に作業場（workspace）が作られます。
2. **「AIセッション」の面を開く。** 設定なしで、PC内のAIの痕跡がそのまま並びます。
3. **監視をひとつ足す。** `watch/example.yaml` を開き、コメントを外して自分のサイトのURLに書き換えて保存します。

```yaml
- id: my-lp
  kind: site        # site / folder / api / command / release / mcp の6種
  name: 自社LP
  url: https://example.com
  every: 6h
```

## 拡張のしかた（Source / Watch / View）

拡張は**フォルダに置いたただのファイル**です。ビルドも申請も要りません。

| 種類 | なにをするもの | 置き場所 |
|---|---|---|
| **Source** | 出来事を川に流す（自分の道具・APIからの取り込み） | `plugins/<名前>/` |
| **Watch** | 見張る対象を YAML で書く（6種の判定） | `watch/*.yaml` |
| **View** | 見せ方を足す（サンドボックス内で動く HTML 画面） | `plugins/<名前>/` |

- フォルダ名の頭に `_` を付けると、その拡張は**読み込まれません**（消さずに止められます）。
- View は隔離された枠の中で動きます。ローカルのファイルやネットワークに直接は触れません。
- 詳しい書き方は、アプリ内の「拡張機能」の面と、`plugins/README.md` に入っています。

## データはどこに保存されるか

**すべてあなたのPCの中だけです。**

| データ | Windows | macOS |
|---|---|---|
| 作業場ぜんぶ | `%APPDATA%\HONJIN\workspace\` | `~/Library/Application Support/HONJIN/workspace/` |
| 出来事の川 | 同 `stream\`（`events.jsonl` ＝ 追記のみ。テキストなので他のツールでも読めます） | 同 `stream/` |
| 監視の定義 | 同 `watch\` | 同 `watch/` |
| 拡張 | 同 `plugins\` | 同 `plugins/` |
| 書いたカード | 同 `vault\`（保存先は設定から変えられます） | 同 `vault/` |
| プロジェクトの一覧（月次報告の送り先を含む） | 同 `data\biz_projects.json` | 同 `data/biz_projects.json` |
| 進捗の記録（追記だけ） | 同 `data\biz_log.jsonl` | 同 `data/biz_log.jsonl` |
| AI が置く進捗の受け取り箱 | 同 `inbox\progress\`（取り込んだものは `_done\`、形が違うものは `_bad\` に30日残す。取り込み済みの控えは `data\biz_inbox_seen.json`） | 同 `inbox/progress/` |
| 月次報告の下書き | 同 `reports\` | 同 `reports/` |
| 発信の構成案・下書き棚・作る前の1問の答え・誰が何をしたかの整理 | 書いたカードの保存先の隣の `_発信キュー\`（`_本人のひとこと.json`・`_誰が何をしたか.json`） | 同 `_発信キュー/` |
| 「ファイル」に登録した場所の一覧 | 同 `data\files_pins.json`（ファイルそのものは写しません） | 同 `data/files_pins.json` |

出来事の中身が外部に送られるのは、上の「できること」の下に書いた、AI に下書き・仕分け・プロジェクトの進捗の記録・月次報告の下書きを頼むときだけです。そのときも、送り先はあなたが選んだ AI（PC の中の Ollama か、あなたが入れている claude／codex の CLI）です。

## 更新

- 起動すると、新しい版が出ていないかを **GitHub Releases の最新** に確認しに行きます。
- 更新は「設定・情報」→「更新を確認」からも実行できます。
- ダウンロード先は **公式リリースの資産だけ**に固定しています（リダイレクト先も毎回確認します）。
  そのため、更新と称して別のファイルを掴まされることがありません。

## アンインストール

Windows は「設定 → アプリ」から HONJIN を削除します。macOS は「アプリケーション」から `HONJIN.app` を捨てます。

- **作業場（Windows: `%APPDATA%\HONJIN\workspace\` ／ macOS: `~/Library/Application Support/HONJIN/workspace/`）は残ります。** 入れ直すとそのまま続きから使えます。
- 完全に消したい場合は、アンインストール後にこのフォルダを手で削除してください。

## よくある質問

<details>
<summary><b>会社のデータを外部に置きたくないのですが</b></summary>

HONJIN は外部にデータを預けません。集めた出来事はあなたのPCの中のファイルとして残ります。
通信するのは、あなたが自分で設定した取得先と、更新確認だけです。
AI に下書き・仕分け・プロジェクトの進捗の記録・月次報告の下書きを頼む機能だけは、選んだ AI に材料が渡ります。PC の中の Ollama を選ぶか、プロジェクト画面の「進捗を書くAI」を「使わない」にすれば、外には出ません。
</details>

<details>
<summary><b>UNIシリーズを使っていなくても意味がありますか？</b></summary>

「AIセッション」「監視」「カード」は単体で使えます。
一方で「講座」「公開サイト」「製品」の面は自社サービス前提なので、空のままになります。
</details>

<details>
<summary><b>ソースは公開しないのですか？</b></summary>

本体は非公開です。代わりに**拡張の仕様を公開**しています。
自分の道具を繋ぎたい場合は、本体を触らずに Source / Watch / View を足してください。
</details>
